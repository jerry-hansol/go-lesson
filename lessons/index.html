Go 코스 인덱스

미션: 미디어 서버 생태계(Pion, MediaMTX, LiveKit)의 Go 코드를 읽고·수정하고·PR을 통과시키는 실무 수준까지. 하루 1시간, 레슨 하나씩.

기초 아크 — 언어 자체 (0001–0007)

레슨주제실습
0001첫 Go 프로그램 — 해부도, go run/build, gofmthello
0002변수·타입·함수 — zero value, 명시적 변환, 다중 반환HLS 세그먼트 계산기
0003에러 처리 — (값, error), %w 래핑, errors.Is, defer해상도 파서
0004슬라이스·맵·for range비트레이트 통계
0005구조체·메서드·포인터 — 리시버 선택, NewX 관례Stream 상태 머신
0006인터페이스 — 암묵적 구현, io.Reader/Writer, 타입 단언Publisher 다형성
0007고루틴·채널·WaitGroup — 동시성 입문병렬 트랜스코딩

실전 아크 — 실무 도구 (0008–0012)

레슨주제실습
0008패키지와 프로젝트 구조 — cmd/, internal/, import 경로mediakit 모듈
0009테스트 — 테이블 드리븐, t.Run, 커버리지segment 패키지 테스트
0010net/http — 패턴 라우팅, JSON, 에러 응답스트림 API
0011select와 context — 타임아웃, 취소 전파취소 가능한 파이프라인
0012공유 상태와 레이스 — Mutex, -race 디텍터레이스 재현→검출→수리

종합 — 캡스톤과 실코드 (0013–0014)

레슨주제실습
0013캡스톤 — 미니 스트림 게이트웨이 (0002~0012 종합)gateway 프로젝트
0014실코드 읽기 — 코드 리딩 방법론 + mediamtx 투어RTMP 경로 추적

Pion·WebRTC 아크 — 프로토콜 지식 × pion 코드 (0015–0020)

레슨주제실습
0015WebRTC 큰 그림 — 시그널링, SDP, PeerConnection 생명주기한 프로세스 두 피어 연결
0016ICE — NAT 순회, STUN/TURN, candidatecandidate 실물 관찰
0017DataChannel과 보안 — DTLS, SCTP, 신뢰성 옵션ping-pong + 옵션 협상
0018RTP와 Track — SSRC/seq/timestamp, 코덱 협상RTP 필드 실측
0019SFU — 1:N 방송, PLI, RTP 포워딩미니 SFU (1→2 중계)
0020실전의 pion — mediamtx·LiveKit 해부, interceptor, WHIP실코드 추적

  • 프로젝트 구조 · 테스트 · HTTP·JSON · select·context · sync·race · 캡스톤 채점표 · 코드 리딩 플레이북
  • WebRTC 개요 · ICE · DataChannel · RTP·Track · SFU · pion 생태계
