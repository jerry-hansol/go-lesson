Lesson 0001 · Go 기초

첫 Go 프로그램 — 해부하고, 실행하고, 부숴보기

MediaMTX도 LiveKit도 결국 func main()에서 시작하는 Go 모듈이다. 오늘은 그 최소 단위를 내 손으로 만들어 실행한다. 예상 소요: 25–30분.

오늘의 목표 (하나만)

내 맥에서 Go 모듈을 직접 만들어 실행하고, Go 프로그램의 최소 해부도(package / import / func main)를 남에게 설명할 수 있다.

1. Go 프로그램의 해부도

Java에서 넘어올 때 가장 먼저 버릴 것: 클래스. Go에는 클래스도, public static void main도 없다. 파일은 패키지에 속하고, 실행 프로그램은 main 패키지의 main 함수에서 시작한다.

package main                 // ① 이 파일이 속한 패키지. 실행 프로그램이려면 반드시 main

import "fmt"                 // ② 표준 라이브러리에서 fmt(포맷/출력) 패키지를 가져온다

func main() {                // ③ 진입점. 인자도 반환값도 없다
    fmt.Println("...")       // ④ Println의 P가 대문자 = 패키지 밖으로 공개된(exported) 함수
}

2. 모듈: go.mod 한 입

Go의 프로젝트 단위는 모듈이다. 루트의 go.mod 파일이 모듈 이름과 의존성을 기록한다 — pom.xml의 대응물인데, 손으로 편집할 일이 거의 없을 만큼 가볍다 (How to Write Go Code).

실행은 두 가지: go run .은 컴파일 후 바로 실행(개발용), go build .는 정적 바이너리 하나를 만든다. JVM 없이 단독 실행되는 파일 하나 — 미디어 서버들을 작은 컨테이너 하나로 배포할 수 있는 이유다.

3. 실습 — 직접 실행하기

터미널을 열고 순서대로. 각 단계의 예상 결과와 다르면 그 지점이 바로 배울 거리다.

  1. 실습 디렉토리를 만들고 이동: 
    mkdir -p ~/Desktop/repo/learn-go/playground/hello
cd ~/Desktop/repo/learn-go/playground/hello
  2. 모듈 초기화: 
    go mod init hello

    예상: go: creating new go.mod: module hello — 열어보면 3줄짜리 파일이다.

  3. hello.go 파일을 만들어 아래 내용 저장 (에디터 자유): 
    package main

import "fmt"

func main() {
	fmt.Println("Hello, 미디어 서버의 세계!")
}
  4. 실행: 
    go run .

    예상: Hello, 미디어 서버의 세계! — 이게 여러분의 첫 Go 프로그램이다.

  5. 바이너리로 빌드해서 실행: 
    go build .
./hello

    예상: 같은 출력. ls -lh hello로 크기를 확인해 보자 — 이 파일 하나면 어디서든 돈다.

부숴보기 (중요 — 에러를 직접 읽는다)

  1. fmt.Println(...) 줄을 지우고(import는 남기고) go run .

    예상: imported and not used: "fmt" — Go에서 안 쓰는 import는 경고가 아니라 컴파일 에러다. Java와 가장 크게 다른 습관 (왜 그런지: Go FAQ). 확인 후 원상복구.

  2. 들여쓰기를 엉망으로 만들고 저장한 뒤: 
    go fmt ./...

    예상: 파일이 표준 포맷으로 복구된다. Go는 포맷 논쟁을 gofmt로 종결했다 (Effective Go — Formatting).
