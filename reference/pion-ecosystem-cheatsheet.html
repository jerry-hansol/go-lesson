pion 생태계 치트시트

pion 모듈 지도와 실코드(mediamtx·livekit)의 의존 구조. 출처: pion org, mediamtx 9934156·livekit 6a64df2 go.mod 실측 (2026-08-20).

모듈 지도 — webrtc는 파사드

pion/webrtc (파사드: PeerConnection·Track·DataChannel API)
├─ 연결   pion/ice ── pion/stun, pion/turn      ← NAT 순회
├─ 보안   pion/dtls ── pion/srtp                 ← 핸드셰이크·미디어 암호화
├─ 데이터 pion/sctp ── pion/datachannel          ← DataChannel 전송
├─ 미디어 pion/rtp, pion/rtcp                    ← 패킷·피드백
├─ 기술   pion/sdp                               ← offer/answer 본문
└─ 확장   pion/interceptor                       ← RTP/RTCP 미들웨어 체인
모듈역할레슨
webrtc/v4브라우저 WebRTC API 대응 파사드. import는 항상 /v4 명시0015
ice/v4, stun/v3, turn/v5candidate 수집·페어링, NAT 순회 서버0016
dtls/v3, srtp/v3키 교환, RTP 암호화0017
sctp, datachannelDataChannel 신뢰성 계층0017
rtp, rtcp, sdp/v3패킷 직렬화, 피드백, 세션 기술0015·0018
interceptorNACK·리포트 등 RTP/RTCP 자동화 플러그인0020

interceptor 체인 (미들웨어 모델)

[앱 코드] → Registry{ ic1 → ic2 → ic3 } → [네트워크]
             │NACK 재전송  │수신 리포트  │커스텀(통계 등)
등록:  reg := &interceptor.Registry{}
       webrtc.NewAPI(webrtc.WithInterceptorRegistry(reg))
구현:  BindRTCPReader/BindRTCPWriter 등을 가진 타입 (암묵 구현, ← 레슨 0006)
실전:  mediamtx internal/protocols/webrtc/stats_interceptor.go
