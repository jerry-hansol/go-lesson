연산코드비고
리터럴s := []int{1, 2, 3}배열([3]int)과 달리 크기 없음

맵 연산

연산코드비고

nil 동작 비대칭 (중요)

nil 슬라이스 (var s []int)nil 맵 (var m map[string]int)

공유(aliasing) 함정 요약

orig := []int{2400, 3100, 2800, 4500}
head := orig[0:2]         // 같은 배열을 본다 (len 2, cap 4)
head[0] = 9999            // orig[0]도 9999
head = append(head, 7777) // cap이 남아 있어 orig[2]를 덮어씀!
  • 독립된 복사가 필요하면 copy 또는 append([]int(nil), s...).
  • 함수 파라미터로 받은 슬라이스를 수정하면 호출자에게 보인다 — 의도가 아니면 복사부터.
