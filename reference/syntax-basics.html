타입값
int, float64 등 숫자0
string""

타입 변환

f := float64(someInt)     // 항상 명시적 — T(v) 형태
i := int(someFloat)       // 소수부 버림(truncate)
  • 암묵적 승격 없음. 타입이 다르면 연산 자체가 mismatched types 에러.
  • 정수/정수 나눗셈은 정수다 — 변환이 안 보이면 정수 연산이다.

함수

func splitSegments(totalSec, segLen int) (int, int) {
    return totalSec / segLen, totalSec % segLen
}

full, rem := splitSegments(95, 6)     // 다중 반환 받기
onlyFull, _ := splitSegments(95, 6)   // 필요 없는 값은 _ 로 버리기
  • 타입은 이름 뒤. 같은 타입 파라미터는 묶어서 a, b int.
  • 다중 반환이 (값, error) 에러 처리 관례의 토대 (추후 레슨).
