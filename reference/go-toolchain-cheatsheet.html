Go 툴체인 치트시트

새 프로젝트를 만들고 실행하기까지 필요한 전부. 출처: How to Write Go Code, cmd/go 문서.

실행 가능한 Go 프로그램의 최소 해부도

package main                // 실행 바이너리의 진입 패키지 (필수 이름)

import "fmt"                // 표준 라이브러리 포맷/출력 패키지

func main() {               // 진입점 함수 — 인자도 반환값도 없다
    fmt.Println("hello")    // 대문자 P = 패키지 밖으로 공개(exported)된 함수
}
  • 클래스 없음. 파일은 패키지에 속하고, 같은 디렉토리 = 같은 패키지.
  • 사용하지 않는 import·지역 변수는 컴파일 에러 (경고 아님). Go FAQ
  • 세미콜론은 쓰지 않는다 (컴파일러가 자동 삽입).

자주 쓰는 명령

명령하는 일Java로 치면
go version설치된 Go 버전 확인java -version
go mod init <이름>현재 디렉토리를 모듈로 초기화 (go.mod 생성)새 pom.xml/build.gradle
go run .컴파일 후 즉시 실행 (바이너리 안 남김)IDE의 Run 버튼
go build .정적 바이너리 생성 (현재 디렉토리에)mvn package — 단, JVM 불필요
go fmt ./...모든 하위 패키지 코드 포맷 (gofmt)포매터 — 단, 유일·공식
go vet ./...흔한 실수 정적 분석SpotBugs 유사
go test ./...모든 하위 패키지 테스트 실행 (추후 레슨)mvn test
go mod tidy의존성 추가/정리 — import에 맞춰 go.mod 동기화의존성 resolve
go envGo 환경 변수 확인—

./...은 "현재 디렉토리와 모든 하위 패키지"라는 뜻의 패턴이다.
