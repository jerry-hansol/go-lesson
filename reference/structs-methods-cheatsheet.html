구조체·포인터·메서드 치트시트

데이터 묶음과 동작 붙이기의 최소 문법. 출처: Go by Example, Go FAQ.

구조체

type Stream struct {
    Name        string
    BitrateKbps int
    Live        bool
}

s := Stream{Name: "a", BitrateKbps: 3000}  // 리터럴 — 필드명 명시 권장
var z Stream                               // zero value — 즉시 사용 가능 (null 없음)
  • 상속·생성자·getter/setter 없음. 첫 글자 대문자 = 패키지 밖 공개.
  • 리터럴에 없는 필드 → unknown field ... in struct literal 컴파일 에러.

메서드 — 리시버 선택 기준 (Go FAQ)

func (s *Stream) Start()           { s.Live = true }  // 포인터 리시버: 원본 수정
func (s Stream)  Describe() string { ... }             // 값 리시버: 복사본 읽기
상황리시버
상태를 수정한다포인터 (필수)
구조체가 커서 복사가 비싸다포인터
하나라도 포인터 리시버가 있다전부 포인터로 통일
작고 읽기만 한다값도 OK
  • 호출은 항상 s.Start() — 컴파일러가 &s/*s를 자동으로 맞춘다.
  • 함정: 값 리시버에서 필드를 수정하면 에러 없이 복사본만 바뀐다 (조용한 버그).

생성자 관례

func NewStream(name string) *Stream {
    return &Stream{Name: name, BitrateKbps: 3000}
}
  • zero value로 충분하면 리터럴로 끝 — New 함수는 초기화 로직이 필요할 때만.
  • 모듈명이 표준 라이브러리 패키지와 겹치면 ambiguous import — 예: Go 1.26에서 go mod init structs 금지.
