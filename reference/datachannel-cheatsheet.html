신뢰성 옵션 (webrtc.DataChannelInit)

옵션타입의미
Ordered*bool순서 보장 (기본 true)
MaxRetransmits*uint16재전송 횟수 상한 — MaxPacketLifeTime과 상호 배타
MaxPacketLifeTime*uint16재전송 유효 시간(ms) — 하나만 지정
용도설정
채팅·파일·제어 명령기본값 (nil) — 신뢰·순서 보장
게임 좌표·실시간 상태Ordered:false, MaxRetransmits:0
자막·텔레메트리 (시한부)Ordered:false, MaxPacketLifeTime:n

콜백 골격 (pion v4)

// 여는 쪽
dc, err := pc.CreateDataChannel("label", nil) // 옵션은 &webrtc.DataChannelInit{...}
dc.OnOpen(func() { dc.SendText("hi") })
dc.OnMessage(func(msg webrtc.DataChannelMessage) { ... })

// 받는 쪽 — OnMessage는 콜백 안에서 '즉시' 등록 (늦으면 그 전 도착분 유실)
pc.OnDataChannel(func(dc *webrtc.DataChannel) {
    dc.OnMessage(func(msg webrtc.DataChannelMessage) { ... })
    // 협상된 옵션 확인: dc.Ordered(), dc.MaxRetransmits()
})

시그널링 골격 (한 프로세스 두 피어)

offer, _ := pc1.CreateOffer(nil)
pc1.SetLocalDescription(offer)
<-webrtc.GatheringCompletePromise(pc1)   // candidate 수집 완료까지 대기
pc2.SetRemoteDescription(*pc1.LocalDescription())
answer, _ := pc2.CreateAnswer(nil)
pc2.SetLocalDescription(answer)
<-webrtc.GatheringCompletePromise(pc2)
pc1.SetRemoteDescription(*pc2.LocalDescription())

흔한 사고

증상원인실측 메시지
초반 메시지가 사라짐OnMessage 등록이 도착보다 늦음 (버퍼링 없음)에러 없음 — 조용한 유실
닫힌 채널에 SendReadyState가 closedio: read/write on closed pipe (error 반환, panic 아님)
옵션 무시됨MaxRetransmits와 MaxPacketLifeTime 동시 지정하나만 지정해야 한다
