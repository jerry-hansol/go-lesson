HTTP·JSON 치트시트 — net/http와 encoding/json

표준 라이브러리만으로 API 서버를 만드는 최소 패턴. 출처: Routing Enhancements for Go 1.22, Go by Example: JSON.

서버 골격

mux := http.NewServeMux()
mux.HandleFunc("GET /streams", listStreams)
mux.HandleFunc("GET /streams/{id}", getStream)
mux.HandleFunc("POST /streams", createStream)
log.Fatal(http.ListenAndServe(":8080", mux))

// 핸들러 = 그냥 함수
func getStream(w http.ResponseWriter, r *http.Request) {
    id := r.PathValue("id")           // {id} 와일드카드
    ...
}

라우팅 패턴 (Go 1.22+)

패턴동작
"GET /streams"GET(+HEAD)만 매칭
"GET /streams/{id}"와일드카드 → r.PathValue("id")
"/health"메서드 생략 = 모든 메서드
등록 안 된 메서드ServeMux가 자동으로 405 + Allow 헤더

JSON

type Stream struct {
    ID          string `json:"id"`
    BitrateKbps int    `json:"bitrate_kbps"`
    Note        string `json:"note,omitempty"`  // zero value면 키 생략
}

json.NewEncoder(w).Encode(v)        // io.Writer로 직렬화 (응답에 바로)
err := json.NewDecoder(r.Body).Decode(&v)  // io.Reader에서 역직렬화 — err 확인 필수
규칙내용
태그 없음JSON 키 = 필드명 그대로 (BitrateKbps)
unexported 필드에러 없이 조용히 제외. go vet이 태그 달린 경우 경고
Jackson 대비어노테이션 → 문자열 태그, ObjectMapper → Encoder/Decoder

에러 응답

http.Error(w, "stream not found", http.StatusNotFound)
return  // ← 반드시! 핸들러는 예외로 중단되지 않는다
  • 상태코드는 상수로: http.StatusOK(200) StatusCreated(201) StatusBadRequest(400) StatusNotFound(404).
  • 상태코드는 첫 WriteHeader가 확정 — 이후 호출은 superfluous response.WriteHeader 로그만 남기고 무시된다. 명시적 WriteHeader는 헤더 설정 후, 바디 쓰기 전에 한 번.
  • 성공 JSON 응답: w.Header().Set("Content-Type", "application/json") → (필요 시 WriteHeader) → Encode 순서.
