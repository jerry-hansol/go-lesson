# 레슨 0001 완료 — ZPD가 예상보다 높다, 페이스 상향

사용자가 레슨 0001(프로그램 해부도, go mod/run/build, gofmt, unused import 에러)을 당일 완료하고 "짧고 쉬웠음"이라고 평가했다(2026-08-19). 툴체인과 프로그램 최소 구조는 확립된 것으로 본다. 시니어 엔지니어에게 절차적 지식은 저항이 거의 없다 — 병목은 Go 고유 관용구 쪽에서 나타날 것이다.

**Implications**
- 레슨 밀도 상향: 레슨당 관련 개념 3~4개까지 묶고, 설명은 Java 대비 위주로 압축
- 절차(명령어 실행류)는 빠르게 통과. 단, "부숴보기"(에러 직접 읽기)와 퀴즈는 유지 — 쉬웠더라도 인출 연습은 저장 강도(storage strength)를 위해 필요
- 진짜 난이도 테스트는 에러 처리·슬라이스 내부·인터페이스에서 온다 — 그 시점에 다시 캘리브레이션 ([[0001-prior-knowledge-baseline]] 참조)
