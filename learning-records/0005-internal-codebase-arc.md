# 사내 코드베이스를 교재로 하는 아크 신설 — 공개 경계 확립

사용자가 사내 Go 프로젝트의 `go.mod` 를 보여주며 "이 프로젝트를 이해하고 개선하는 데 커리큘럼이 충분한가" 물었고(2026-08-20), 코드 대조 결과 이해에는 충분하지만 개선에는 6가지 갭(저수준 pion 설정, RTCP 직접 조작, 내장 TURN, WebSocket 시그널링, 성능 진단, E2E 테스트 패턴)이 있었다. 그 갭을 그 코드베이스 자체로 메우는 맞춤 아크(0021~0027)를 신설했다(2026-08-21).

**Implications**
- 이 아크는 사내 코드의 경로·주석·운영 지표를 인용하므로 **로컬 전용**(`sidecar-arc/`, 루트 .gitignore). 공개 Pages 사이트는 0001~0020 경계를 유지한다 — 앞으로 사내 코드를 다루는 레슨이 추가될 때도 이 경계를 지킬 것
- 실습 형태가 바뀌었다: "코드 작성" → "추적·실행·측정". 회사 레포는 읽기 전용으로 다룬다
- 학습 목표가 "언어 습득"에서 "근거 있는 개선 제안"으로 이동 — 아크 완주 후 사용자가 실제 제안/PR 경험을 가져오면 그것이 다음 캘리브레이션 입력
- 이 코드베이스는 한국어 주석에 이슈 키와 설계 근거(실패한 시도와 그 이유까지)가 촘촘히 달려 있어 교재 품질이 높다 — Go 심화 소재가 실물로 존재하므로, 앞으로도 언어 기능을 추상 예제보다 이 코드로 가르치는 편이 전이가 잘 된다
