# 난이도 캘리브레이션 확정 — 레슨당 개념 3~4개가 "딱 좋아"

레슨 0002(변수·타입·함수, 개념 3개 + 부숴보기 3개)에 대해 사용자가 "딱 좋아"라고 확인했다(2026-08-19). LR-0002에서 상향한 밀도가 현재 ZPD에 정확히 맞는다 — 이 밀도를 기초 아크의 표준으로 고정한다.

같은 날 사용자가 여러 레슨 일괄 생산을 요청해 기초 아크 전체(0003 에러 처리 → 0004 슬라이스·맵 → 0005 구조체·메서드 → 0006 인터페이스 → 0007 고루틴·채널)를 배치 발행했다.

**Implications**
- 소비가 자기 페이스로 바뀌므로 레슨별 실시간 캘리브레이션이 불가능 — 각 레슨 퀴즈 Q1을 직전 레슨 복습으로 설계해(간격 반복) 배치 안에서도 인출 연습이 이어지게 함
- 배치 소진 후 사용자 보고(어디서 막혔나, 퀴즈 오답)를 다음 캘리브레이션 입력으로 사용
- 0007(동시성)이 이 밀도로 소화되면 기초 아크 졸업 — 다음은 실전 아크(net/http 미니 서버 → 실제 미디어 코드베이스 읽기)
