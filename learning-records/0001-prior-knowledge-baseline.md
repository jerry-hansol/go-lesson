# 사전 지식 베이스라인: 시니어 백엔드(Java), Go는 거의 처음

사용자는 Java/Spring Boot 시니어 백엔드 엔지니어지만 Go는 배워본 적이 없다고 밝혔다(2026-08-19). 프로그래밍 일반 개념(HTTP, 동시성이라는 개념 자체, 테스트, 빌드 도구)은 재교육이 불필요하고, Go 고유의 문법·관용구·툴체인·동시성 모델은 처음부터 가르쳐야 한다. ZPD 산정 시 "프로그래밍 초심자용 설명"은 지루함을, "Go 경험 전제"는 과부하를 유발한다.

**Implications**
- 변수/조건문/반복문 같은 프로그래밍 기초 설명은 생략 — Go 문법의 *차이점*만 짚는다
- Java 개념(인터페이스, 예외, 스레드, Maven)과의 대비가 효과적인 설명 도구
- 학습 동기가 미디어 서버 생태계([[MISSION.md]]) — 예제를 스트리밍 도메인에 연결하면 전이가 잘 된다
